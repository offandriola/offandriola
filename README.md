### 🚀 Projeto em Destaque

#### 🧠 [CheckAI — Classificação de Conteúdos Políticos](https://github.com/offandriola/ml-checkai)

Projeto acadêmico de **Machine Learning e Processamento de Linguagem Natural (NLP)** voltado à análise de alegações políticas e identificação de possíveis conteúdos desinformativos em português.

A aplicação integra coleta e processamento de dados, modelos de classificação, consulta a fontes externas e uma API REST para disponibilização dos resultados.

**Tecnologias utilizadas:**

`Python` `FastAPI` `Machine Learning` `NLP` `Scikit-learn` `MySQL` `Docker` `APIs REST`

[🔗 Acessar repositório](https://github.com/offandriola/ml-checkai)
